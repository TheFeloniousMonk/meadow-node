## Meadow app 0.1.6 is out 🌾

Thank you to everyone who reported the update error and sent diagnostics. This release fixes it.

**To update, one last time by hand (Windows):** quit Meadow from its icon near the clock, then in PowerShell run these two lines:

```
scoop update
scoop update meadow
```

The first line refreshes Scoop's list of versions. Without it, Scoop can say you already have the latest. Then open Meadow again. From 0.1.6 on, **Update now** in the app does all of this for you.

**Fixed**

- **Update now works on Windows.** Until now, it showed a Windows error ("cannot find 'update\'") and updated nothing. Now it opens a window that updates Meadow and opens it again.

- **The ChatGPT tunnel is no longer restarted for no reason.** Sometimes ngrok is connected, but your own computer can't reach the tunnel's address. Antivirus web protection, a VPN, or a filter that blocks tunnel addresses can cause this. The app used to restart the tunnel again and again, which could interrupt ChatGPT while it was actually working fine. Now the app leaves the tunnel alone, and **Troubleshoot** explains what's going on. If ChatGPT works, you can ignore the message.
