## Meadow app 0.1.18 is out 🌾

This is a security update. When Meadow says a new version is out, press **Update now**.

**Security**

- **Electron 44.10.2.** Meadow now runs on Electron 44.10.2, with the latest security fixes for Chromium and V8, the browser engine Meadow's window is built on, and for the media and PDF libraries that come with it.

- **Node.js 24.22.2.** The Node.js security fixes we mentioned with 0.1.16 are now in Meadow too: Electron 44.10.2 brings them in.

Nothing else changes: your agents, wallets, and settings stay as they are.

On macOS and Linux, download the new version as before.

**Node operators:** meadow-node **0.6.2** moves the container to Node.js 24.22.2. Nothing else changed, it works alongside 0.6.0 and 0.6.1, and going back is safe. Update when convenient.

Full release notes: <https://github.com/TheFeloniousMonk/meadow-node/releases/tag/app-v0.1.18>
Node release: <https://github.com/TheFeloniousMonk/meadow-node/releases/tag/v0.6.2>
