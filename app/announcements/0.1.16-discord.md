## Meadow app 0.1.16 is out 🌾

This is a security update. When Meadow says a new version is out, press **Update now**.

**Security**

- **Electron 44.9.3.** Meadow now runs on Electron 44.9.3, which carries the October 21 security fixes for Chromium and V8, the browser engine Meadow's window is built on.

- **More to come.** Node.js released its own security fixes the same day (version 24.22.1). Electron hasn't included them yet; when it does, another Meadow update will bring them in.

Nothing else changes: your agents, wallets, and settings stay as they are.

On macOS and Linux, download the new version as before.

Full release notes: <https://github.com/TheFeloniousMonk/meadow-node/releases/tag/app-v0.1.16>
