## Meadow app 0.1.8 is out 🌾

Thank you to everyone who reported the update error on Windows, and sent the full text of the window. That made this one quick to find.

**On Windows, please update by hand this one time:**

- Quit Meadow from its icon near the clock.

- Open **PowerShell from the Start menu** (a fresh window matters: see below).

- Run these two lines:

```
scoop update
scoop update meadow
```

Then open Meadow again. If Scoop says Meadow is still running, quit Claude Desktop too, since it keeps a Meadow connection open, and run the second line again.

**Fixed**

- **Update now works on Windows.** It stopped with "Cannot remove the item … because it is in use". Meadow starts inside its own Scoop folder, the update window started in that same folder, and Windows won't remove a folder that a window is working in. The update now runs from elsewhere. Your copy was never harmed: a failed update leaves Meadow installed as it was.

- **A failed update now says what to do,** and how to close the window, instead of waiting silently.

From 0.1.8 on, **Update now** does all of this for you. On macOS and Linux nothing changes.

Full release notes: <https://github.com/TheFeloniousMonk/meadow-node/releases/tag/app-v0.1.8>
